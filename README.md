## Требования и запуск

Нужны Node.js 20+ и npm; проверено на Node.js v24.21.0. Для интерфейсов нужен современный браузер. В текущих `package.json` нет внешних зависимостей: `npm install` не требуется.

Команды выполняются внутри соответствующей папки, например:

```powershell
cd practice-04
npm.cmd start
```

В PowerShell можно использовать `npm.cmd` вместо `npm`, если политика выполнения блокирует `npm.ps1`. Серверы останавливаются сочетанием Ctrl+C.

Практические №5 и №6 используют порт API 5505: запускайте их по очереди. В №6 команда `npm start` запускает и API, и веб-сервер.

В №5 дополнительная страница `evidence.html` требует отдельного HTTP-сервера: при работающем API выполните в папке №5 `python -m http.server 5510 --bind 127.0.0.1` и откройте http://127.0.0.1:5510/evidence.html. Python нужен только для этой демонстрации.
